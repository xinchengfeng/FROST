# Scalar-SC controls and FROST-LT reconstruction (current Fig. 9)

This directory contains the six-method, three-target comparison for **current
Fig.9**. Historical files named `fig10_*` or scripts describing “Fig.10” refer
to this same experiment, not the current hardware figure. The three targets
are BSDS500 IDs 2018, 43033 and 235098; seeds 101/202/303 at L4096 yield 54 final
measurements and 18 three-stream aggregates.

The controls are SExp-FSM, Horner-SC, Bernstein-SC, Bernstein-LD and
Bernstein-Strat. They are explicitly documented adaptations of scalar SC
primitives; additional QMC/stratification controls are not presented as
reproductions of complete published softmax accelerators. All share each
target's frozen Transformer and non-attention kernels. The scalar controls
have only these three targets, not dataset-wide 200-image measurements.

## Prepare dependencies and data

Use the repository environment and a C++17 compiler (`g++`). The historical
exact Python pins are in `requirements.txt` and retained for provenance.

From the repository root:

```bash
python experiments/reconstruction_original/prepare_data.py \
  --records /path/to/FROST_Experimental_Records \
  --bsds-images /path/to/BSDS500/data/images --targets scalar
```

This populates `results/`, `checkpoints/`, `inputs/` and `legacy_runtime/`
from public saved predictions/weights and hash-verified official references.
The selected shared operator is copied from the data archive's FROST-LT
checkpoint. The legacy `stage2_pilot_ID.npz` inputs are assembled losslessly
from archived seed101 arrays, not generated by a new run. No reference pixels
or large fitted weights are committed to the code repository.

From this directory, build the native kernels:

```bash
python -c "import sys; sys.path.insert(0,'source'); import sc_baselines; sc_baselines.build()"
python source/local_tt.py
python legacy_runtime/source/scripts/fast_finite.py
python source/horner.py
```

## Regenerate the figure from archived outputs

With a legitimately installed Arial font (or its directory supplied through
`FROST_FIGURE_FONT_DIR`), run:

```bash
python source/make_figure.py
```

The script recomputes each plotted PSNR/SSIM/MSE and verifies recorded metrics,
then writes `figure/FROST_reconstruction_SC.pdf`, SVG, PNG and local summary
CSVs/JSON. Original 64x64 reference/reconstruction pixels remain raster image
information; labels, lines and geometry are vector elements. Figure generation
does not train models, perform new inference, denoise or invent image detail.

## Verify finite-event kernels

For a small check requiring NumPy and a C++17 compiler, without PyTorch,
datasets or fitted weights, run from this directory:

```bash
python smoke_native.py
```

This compiles three native kernels in a temporary directory and compares four
literal Python versus C++ threshold-count cases at L64/L256 using explicitly
synthetic CDF fixtures. It verifies count mass and implementation agreement;
it does not reproduce trained-model reconstruction quality.

For the full checks with the archived trained operator and PyTorch installed:

```bash
python source/verify_local.py checkpoints/local33_r16_max8_aug.pt
python source/verify_stratified.py checkpoints/local33_r16_max8_aug.pt
```

These compare compiled threshold logic with literal Python event/count
implementations and test probability mass, shift invariance and sampler
expectations. Their outputs are implementation diagnostics, not extra image
reconstruction observations.

## Re-run the six methods

The commands below reuse saved result pairs. To measure again, first use a
separate working copy and move the desired `results/ID_METHOD_S*.npz`/`.json`
pairs out of that copy, preserving the original archive. Then run:

```bash
python source/evaluate.py --method SExp --workers 1
python source/evaluate.py --method Horner --workers 1
python source/evaluate.py --method Bernstein --workers 1
python source/evaluate.py --method Bernstein_QMC --workers 1
python source/evaluate.py --method Bernstein_stratified --workers 1
python source/evaluate.py --method LocalTT33_stratified --checkpoint checkpoints/local33_r16_max8_aug.pt --workers 1
python source/make_figure.py
```

## Refit the selected probability operator (optional, expensive)

Use a separate copy because these scripts overwrite named training/selection
outputs. Archived `results/calibration_rows.npz` supplies the 12/4-image
operator fitting/validation split, excluding the three displayed targets.

```bash
python source/train_candidates.py --name local33_r16_max8_aug --basis local --states 33 --rank 16 --bound 8 --encoding max --augment --steps 12000
python source/select_finite.py
```

Candidate selection additionally expects the candidate checkpoints listed in
the archived protocol. To recreate every exploratory candidate, follow the
per-configuration commands in `ARCHIVED_previous_README.txt`; those are not
additional main-figure measurements. `source/summarize.py` describes an older
intermediate method set; use `source/make_figure.py` for the final six-method
figure. `source/diagnose.py` and `*_DIAGNOSTIC` records are numerical diagnostics,
not finite-SC baselines. CPU wall times are not hardware power or latency.
