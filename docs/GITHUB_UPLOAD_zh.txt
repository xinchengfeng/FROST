FROST：从下载到GitHub发布的完整步骤
=================================

一、下载与解压

1. 下载FROST_GitHub_Repository_20261022.zip。
2. 解压得到FROST文件夹。打开后应直接看到README.md、experiments、
   hardware、figures、tools、docs、CITATION.cff和requirements.txt。
3. GitHub需要上传这些实际文件和目录。仅把ZIP文件上传到仓库，
   GitHub不会自动将其展开为代码目录。
4. 本次ZIP未包含.git历史；也没有替你在GitHub创建或发布任何仓库。

二、推荐使用GitHub Desktop上传（不需要命令行）

1. 在https://github.com/注册或登录自己的账户。
2. 从https://desktop.github.com/下载GitHub Desktop，安装并登录同一账户。
3. 在GitHub Desktop选择File→New repository（或Create a New Repository）。
4. 按下面填写：
   Name：FROST
   Description：Research code for stochastic Transformer inference with tensorized finite-state operators.
   Local path：选择你电脑上存放GitHub项目的父目录。
   Initialize this repository with a README：可以勾选，稍后用完整README替换。
   Git ignore：None（代码包已有完整.gitignore）。
   License：None（此步骤不替版权人选择项目许可证）。
5. 点击Create repository。桌面软件会在Local path下建立FROST目录。
6. 在文件管理器中打开刚建的仓库目录；再打开下载解压的FROST目录。
   将解压目录里面的全部文件和文件夹复制到仓库目录，替换空白README。
   应看到仓库根目录直接包含README.md、experiments、hardware等；
   不应变成FROST/FROST/README.md这种额外嵌套。
   确保.gitignore、.gitattributes、.github也复制了；保留Desktop生成的.git。
7. 回到GitHub Desktop的Changes页面，查看待提交文件。
   本次代码包已经剔除大模型、完整结果、波形、编译缓存等。
   在Summary填：Add FROST research code
   点击Commit to main（若分支名显示master，就按当前分支名称提交）。
8. 点击Publish repository。
   Name保持FROST；账户选择你实际要发布的账户或机构。
   想公开代码，取消勾选Keep this code private；若仍在内部核对，可先保留。
   点击Publish repository完成上传。
9. 选择Repository→View on GitHub，检查网页根目录确实显示完整代码和README。
   注意：本地Commit只是保存版本；Publish repository/Push origin才上传到GitHub。

三、补充仓库信息

1. 仓库网页右侧About旁齿轮：
   Description可使用上面的文字；Topics可填stochastic-computing、transformer、
   tensor-train、finite-state-machine、attention。
2. 数据在Zenodo正式公开后，把真实版本DOI写入docs/DATA.md，并在README
   链接数据归档。不要填私人uploads编辑网址或推测DOI。
3. 在CITATION.cff补入真实repository-code网址。取得代码归档DOI后再补doi。
4. 软件作者目前填写Xincheng Feng；论文合作者与研究指导在AUTHORS.md说明。
   若软件实际有其他创建者，按真实贡献调整。
5. 项目许可证尚未在本次整理中决定。若版权人确认采用MIT等软件许可，
   在仓库根目录添加相应LICENSE，并保持第三方许可和版权声明。
   数据集的CC BY4.0不会自动成为研究代码的许可证。

四、创建投稿使用的固定版本

1. 先完成上述文件、真实网址和许可证等元数据调整并Push origin。
2. GitHub仓库页面右侧点击Releases→Draft a new release。
3. Choose a tag中输入v1.0.0，选择Create new tag，Target选实际主分支。
4. Release title填写：FROST v1.0.0
5. Describe this release可填写：
   Research code accompanying the FROST manuscript, including operator,
   Transformer, FROST-LT, scalar-SC baseline and hardware evaluation workflows.
   Large experimental records and checkpoints are provided in the data archive.
6. 确认是这次投稿准备采用的代码版本后，点击Publish release。
   GitHub会自动为该tag提供Source code ZIP/tar.gz，不必再次上传全部代码。
7. 保存仓库网址、release网址及完整commitSHA。代码后续变更时，新建版本，
   保持论文所引用版本可追溯。
8. 建议再将同一代码版本归档到Zenodo，Resource type选择Software，取得
   独立代码DOI。可手动上传该release源码ZIP，也可按Zenodo说明连接GitHub。
   论文Code availability写真实仓库网址、版本/commit及代码DOI。

五、后续修改如何更新

1. 修改电脑上Desktop管理的仓库文件。
2. GitHub Desktop→Changes→填写Summary→Commit→Push origin。
3. 不需要每次重新新建GitHub仓库。
4. 若修改了软件版本或论文实际使用的实现，适时创建新的release标签。

六、命令行替代方法（已经熟悉Git时使用）

先在GitHub网页创建空仓库FROST，不预先初始化README、.gitignore或LICENSE。
然后在解压的FROST根目录打开终端，按实际用户名替换网址：

git init
git branch -M main
git add .
git commit -m "Add FROST research code"
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/FROST.git
git push -u origin main

依照GitHub官方流程完成认证；不要把密码、token或私钥写入代码或提交。
如果使用前面的Desktop流程，不需要再重复这组初始化命令。
