# Historical hardware source

These directories retain source from the earlier `FROST_Code.zip` publication
bundle: `l64`, `fused_baselines`, `resource_figures` and `final_figures`.
They are not the canonical current-paper hardware workflow. Some historical
scripts use original workstation paths or depend on results in that older
archive; do not use them to replace the final Stage5 SC comparison. The
original archives and source provenance establish their context.

For current Fig.10 and Tables3–4 use `../stage3`, `../stage5` and the portable
`../stage6/reproduce_figures.py`. Compiled binaries, build objects, waveforms,
older result copies and licensed fonts are intentionally not vendored here.
